# PiSun-Digital-Thermal

PiSun system for Raspberry Pi Zero 2 W with InfiRay Tiny1-C digital thermal camera.

## Features
- Tiny1-C 256x192 thermal camera
- CCI over I2C
- VoSPI over SPI
- NumPy accelerated thermal processing
- MediaMTX main camera
- PiSun web interface
- Two PWM servo outputs

## Installation
On a fresh Raspberry Pi run:

    git clone https://github.com/matforAI/PiSun-Digital-Thermal.git
    cd PiSun-Digital-Thermal
    sudo bash install.sh

The installer installs Git and required dependencies automatically.
